TROUBLESHOOTING:

Issue: "API rate limit" error
└─ Solution: Finnhub free tier allows 60 calls/min
   - If you hit the limit, wait 1-2 minutes
   - Project caches prices for 1 minute to avoid this

Issue: "Invalid API key"
└─ Solution: Make sure key is in .env file correctly
   - Check: cat .env
   - Should show: FINNHUB_API_KEY=your_actual_key

Issue: Still want to test without API key?
└─ Solution: Use mock data mode temporarily
   - Edit: config.py
   - Change: USE_MOCK_DATA = True
   - Then run the app again
